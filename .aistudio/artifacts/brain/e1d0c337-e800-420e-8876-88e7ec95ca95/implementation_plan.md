# 「メンデルの畑」エンドウ遺伝シミュレーター 実装計画

高校生がChromebookを使って1人でエンドウの栽培・交配・サヤ割り収穫を追体験しながら、優性の法則・分離の法則・検定交雑・独立の法則を直感的に発見・習得できる教育シミュレーションWebアプリケーションの設計計画です。

---

## ユーザー確認・重要決定事項

> [!IMPORTANT]
> ユーザー様からの回答に基づき、以下の3つの主要方針を確定しました：
> 1. **ガイドスタイル**: メンデル先生のアドバイスと吹き出しヒントつき（生徒が迷わず、つぼみの除雄や受粉の理屈を自然に理解できる親切な学習導線）。
> 2. **演出・効果音**: Web Audio API による心地よいサヤ割りプチプチ音・収穫ファンファーレ（ヘッダーでワンタップで消音/ON切り替え可能）。
> 3. **ビジュアルスタイル**: 温かみのある植物手帳・ボタニカル風デザイン（落ち着いたクラフトペーパー調背景、セージグリーン・アースカラー、手描き風SVGエンドウ豆・植物・花）。

## 1. 概要と学習価値

### 目的とターゲット
- **対象**: 高校生物・理科を学ぶ高校生（Chromebookでの自主学習）。
- **価値**: 教科書で丸暗記しがちな「3:1」「9:3:3:1」「検定交雑」を、自分の手で「純系の種まき → つぼみの除雄 → 筆での受粉 → サヤ割り → 粒の集計」を通じて追体験し、大数の法則により理論比に収束していく過程を体感できる。
- **安心設計**: ログイン不要、名前等の入力不要、進捗はブラウザ（`localStorage`）に自動保存され、いつでも続きから再開可能。

## 2. ユーザー体験と画面遷移（UX & Visual Design）

```
┌────────────────────────────────────────────────────────┐
│  「メンデルの畑」 ヘッダー (レベル切替 / 音声ON/OFF / リセット)   │
├──────────────────────────┬─────────────────────────────┤
│   左側: インタラクティブ畑・栽培   │   右側: 収穫台 / 集計グラフ / ノート   │
│                          │                             │
│  [12区画の畑グリッド]      │  【タブ切替】               │
│  ・種まき (種袋から選択)    │  ① 収穫台 (サヤ割り演出)      │
│  ・時間進行ボタン (6段階)    │  ② 統計・比率推移グラフ      │
│  ・株タップ → 花アップ      │  ③ 謎解きノート (仮説と検証)   │
│    (つぼみ:除雄 / 開花:筆受粉)│  ④ 種袋 (ストックした豆一覧)  │
│                          │                             │
│  メンデル先生のひとくちガイド  │  [全部割る] [種袋へ保存]      │
└──────────────────────────┴─────────────────────────────┘
```

### レベル別カリキュラム
1. **Lv1 優性の法則**
   - 課題: 純系の丸（AA）としわ（aa）をまき、人工交配して F1 のサヤを収穫。
   - 発見: F1 の豆が「すべて丸」になることを自分の目で確かめる。
2. **Lv2 分離の法則**
   - 課題: F1 の豆（Aa）をまいて自家受精させ、F2 を収穫して数える。
   - 発見: 丸：しわ ≒ 3：1 になること、数を増やすほど 0.75 に近づく推移グラフを確認。メンデルの実測値（5474：1850）と照合。
3. **Lv3 検定交雑（テストクロス）**
   - 課題: 遺伝子型が隠された丸い豆3粒（AA / Aa 混在）が渡される。しわ（aa）と交配させ、収穫した子の表現型からどれが AA でどれが Aa かを推理・判定する。
   - 発見: 子にしわ（aa）が出る株は Aa、すべて丸になる株は AA。正解すると種袋に遺伝子型ラベルが授与される。
4. **Lv4 独立の法則（2遺伝子座）**
   - 課題: 丸・黄（AABB）× しわ・緑（aabb）の交配 → F1（AaBb）→ 自家受精で F2 を収穫。
   - 発見: 丸黄 : 丸緑 : しわ黄 : しわ緑 ≒ 9 : 3 : 3 : 1 を発見。形と色が互いに独立して遺伝することを理解。

## 3. 主要操作とインタラクション仕様

### A. 畑と植物の成長段階
- 畑は最大12株の区画グリッド。
- 成長段階（6段階）:
  1. `SEEDED`（種まき済み・土の盛り上がり）
  2. `SPROUT`（発芽・小さな双葉）
  3. `GROWING`（成長・巻きひげと青葉）
  4. `BUD`（つぼみ★除雄が可能）
  5. `FLOWER`（開花★筆で受粉が可能 / 除雄済みでなければ自家受精準備）
  6. `PODS`（サヤ実り★収穫可能）
- 「時間を進める」ボタンでスムーズな植物アニメーションとともに段階進行。

### B. 花のアップ（モーダル / フォーカス表示）
- **つぼみ段階**:
  - 花弁の内側にピンセット／ハサミのアフォーダンス。おしべ（黄色い葯）をドラッグまたはタップして取り除く（除雄）。
  - 除雄に成功すると「除雄完了（自家受精を防ぎました）」のステータスに変化。
- **開花段階**:
  - 「受粉用の筆」ツール。花粉採取元の株を選び、めしべの柱頭をタップして花粉を付ける。
  - 受粉相手の親株IDが記録される。
- **自家受精ルール**:
  - 除雄していない花は、他の花粉をつけようとしても**必ず自家受精**。
  - 除雄したのに花粉をつけなかった花は**実らない（受粉失敗）**。
  - 収穫時に「この株は自家受精でした」「この株は [株A] × [株B] の交配でした」と履歴を明示。

### C. 収穫台とサヤ割りアニメーション
- 収穫した株のサヤが並ぶ（1株あたり4〜8サヤ、1サヤあたり4〜8粒）。
- サヤをタップすると、弾けるアニメーションと「プチッ」という快音とともにサヤが開き、中の豆が露出。
- **丸豆**: つるりとした光沢ハイライトのある球形。
- **しわ豆**: くぼみ・しわの凹凸テクスチャが入った特有の歪み形状。
- **色（Lv4）**: 新鮮な豆イエロー（優性）と若草グリーン（劣性）。
- 「一括で割る」ボタンで心地よく連続開封可能。

### D. 集計グラフと大数の法則
- 今回のサヤ割り結果 + レベル累計の度数・比率表。
- **累計推移折れ線グラフ**:
  - 横軸: 数えた豆の総数（10個、50個、200個、500個...）
  - 縦軸: 丸の比率（0.0 〜 1.0）
  - 目安線: $y = 0.75$（3:1 理論値）に破線。
  - 初めは激しくブレる比率が、数をこなすにつれて 0.75 へピタリと収束していく大数の法則を直感。
  - メンデル本人の実測データ（丸5474：しわ1850、比率0.7474 ≒ 2.96:1）のピン留め比較。

### E. 謎解きノート（仮説・検証・パネット方形）
- 各レベルの導入でメンデル先生からの問いかけ。
- 複数の仮説から「自分の考え」を選んでノートに記録。
- 収穫・集計を完了したタイミングで「検証する」ボタンが押せるようになり、正解発表、パネット方形（Punnett Square）の視覚的解説、遺伝子型の分離比・表現型比のまとめがノートに永続記録される。

## 4. 厳密な遺伝モデル・計算エンジン（`src/utils/genetics.ts`）

```
                     [母株]                   [花粉親株]
                   Aa (形)                  aa (形)
                      │                        │
             ┌────────┴────────┐      ┌────────┴────────┐
             ▼                 ▼      ▼                 ▼
          配偶子 A           配偶子 a 配偶子 a        配偶子 a
          (p=0.5)           (p=0.5)  (p=0.5)          (p=0.5)
             │                 │      │                 │
             └────────┬────────┴──────┴────────┬────────┘
                      ▼                        ▼
                   受精卵 1                 受精卵 2 ...
                   (母配偶子 × 父配偶子 で独立に胚を決定)
                      │
                      ▼
             豆の表現型 = その豆の中の胚(子)の遺伝子型
```

- **独立な乱数生成器**: シード指定可能な PRNG（Mulberry32）を実装し、再現性のあるシミュレーションと単体テストを担保。
- **配偶子分離**:
  - 形: $A$ または $a$ を独立に $p = 0.5$ で選択。
  - 色: $B$ または $b$ を独立に $p = 0.5$ で選択（連鎖なし・独立）。
- **受精**:
  - 胚珠1つ（＝豆1粒）ごとに、母株配偶子1個と父株配偶子1個を独立に組み合わせて子の遺伝子型を決定。
  - 例: $Aa$ 株の自家受粉では、同一サヤ内で $AA, Aa, aA$（丸）と $aa$（しわ）が約 3:1 で混在実生。
- **開発用検証モード (`?check`)**:
  - URL に `?check` パラメータが付与された場合、起動時に自動で:
    1. F2（$Aa \times Aa$）を 10,000 粒シミュレート $\to$ 丸比率 $0.75 \pm 0.01$ を検証。
    2. Lv4 F2（$AaBb \times AaBb$）を 10,000 粒シミュレート $\to$ 9:3:3:1（丸黄 56.25%, 丸緑 18.75%, しわ黄 18.75%, しわ緑 6.25% 各 $\pm 1\%$）を検証。
    3. 結果をブラウザ `console.log` および画面最下部の検証ドロワーに即座に表示。

│   ├── MendelGuide.tsx   # メンデル先生のヒント吹き出し

├── types.ts              # 遺伝子型, 表現型, 株, サヤ, ゲーム状態の型定義
└── App.tsx               # 全体レイアウト, タブ管理, 状態統合

### 外部依存関係
- 完全クライアントサイド動作（サーバー通信なし、GitHub Pages対応）。
- アイコン: `lucide-react`。
- アニメーション: CSS transitions & `motion`（または軽量CSS）。
- グラフ: 自前SVG（軽量・外部チャートライブラリ不要で高速）。
- 音声: ブラウザ標準の `AudioContext` によるプログラマティック合成（外部mp3ファイル読み込み不要、オフラインでも完全動作）。
