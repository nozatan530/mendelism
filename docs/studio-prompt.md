# studio-prompt — mendel-garden

## 第1部：最初に貼るプロンプト

```
「メンデルの畑」という、エンドウの栽培・交配・収穫を追体験しながら遺伝の法則（優性・分離の法則・検定交雑・独立の法則）を学ぶシミュレーターを作ってください。
利用者は高校生で、自宅の Chromebook で1人で自主学習として使います。自分のペースでレベルを進め、途中でやめても続きから再開できます。

# 遺伝のモデル（この規則を厳密に守ること）
- 形の遺伝子：A＝丸（優性）、a＝しわ（劣性）。AA と Aa は丸、aa はしわ
- 子葉の色の遺伝子：B＝黄（優性）、b＝緑（劣性）。Lv4 のみ使う
- 株は遺伝子型を持つ（例 {shape:"Aa", color:"Bb"}）
- 配偶子：各遺伝子座から2つのうち1つを確率1/2で独立に選ぶ。A と B は独立（連鎖なし）
- 受精：胚珠1つごとに、母株の配偶子1つと父株（花粉の株）の配偶子1つを独立に乱数で作って合わせる
- 豆の形・子葉の色は「その豆の中の胚（子）の遺伝子型」で決まる。母株の遺伝子型ではない。
  → 例：Aa の株を自家受精させると、同じサヤの中に丸としわの豆が混ざって実る
- 除雄していない花は必ず自家受精になる。除雄していない花に他の株の花粉をつけても無効（自家受精のまま）
- 除雄したのに受粉させなかった花は実らない
- 1株のサヤ数は4〜8、1サヤの豆の数は4〜8でランダム
- 乱数は1か所の関数にまとめ、シード指定できるようにする
- 開発用：URL に ?check をつけると、F2（Aa×Aa）を10000粒、Lv4 の F2（AaBb×AaBb）を10000粒シミュレートし、比率をコンソールと画面下に表示する。期待値は 丸0.75：しわ0.25、9：3：3：1（各±1%程度）

# レベル
- Lv1 優性：純系の丸（AA）としわ（aa）の豆をまき、交配して F1 を収穫。F1 の豆がすべて丸になることを確かめる
- Lv2 分離の法則：F1 の豆をまいて自家受精させ、F2 を収穫して数える。丸：しわ ≒ 3：1 を見つける
- Lv3 検定交雑：遺伝子型が隠された「丸い豆」3粒（AA と Aa が混在）が渡される。しわ（aa）と交配して、どれが AA か Aa かを見抜いて回答する
- Lv4 独立の法則：丸・黄（AABB）× しわ・緑（aabb）→ F1 → 自家受精で F2。9：3：3：1 を見つける
- 前のレベルのミッションを達成すると次のレベルが開く

# 画面と操作
1. タイトル／レベル選択：各レベルのカード（達成状況）、謎解きノートの埋まり具合、「続きから」ボタン
2. 畑：区画（最大12株）に、種袋から豆を選んでまく。「時間を進める」ボタンで 発芽→成長→つぼみ→開花→サヤ→収穫可 と段階が進む（アニメーションで早送り）。株をタップすると株の情報（親・世代）を表示
3. 花のアップ（つぼみ・開花の株をタップで開く）：
   - つぼみの段階でのみ「除雄」ができる。おしべをドラッグ（またはタップ）でつまんで取り除く操作
   - 開花後、「筆」で別の株の花から花粉をとり、除雄した花のめしべにつける（花粉をとる株を選ぶ→めしべをタップ）
   - 何もしなければ自家受精。どの受粉が起きたかは記録し、収穫時に「この株は自家受精でした」などと分かるようにする
4. 収穫台：収穫した株のサヤが並ぶ。サヤをタップすると割れるアニメーションで中の豆が見える。丸の豆はつるっとした球、しわの豆はしわの入った形で描き分ける（Lv4 は黄／緑の色も）。全部割ると自動で数を集計。「全部割る」ボタンもつける
5. 集計：今回の数と、そのレベルの累計の数・比を表示。累計の比の推移を折れ線グラフ（横軸：数えた豆の合計、縦軸：丸の割合、0.75 に目安線）。メンデルの実測値（丸5474：しわ1850）と並べて表示
6. 謎解きノート：各レベルに問いがある（例「なぜ F1 は全部丸になったのだろう？」「F2 で丸としわはどんな比になる？」）。選択肢から仮説を選んで記録 → 栽培で確かめたあと答え合わせと短い解説（パネット方形の図つき）が出て、ノートのページが埋まる
7. 種袋：収穫した豆を「世代・親・形（・色）・粒数」でまとめて保管。遺伝子型は表示しない（見た目だけ）。Lv3 で見抜いた豆には遺伝子型のラベルがつく

# 見た目
- 中高生向けで、親しみやすい畑と植物のイラスト（SVG または CSS で描く。画像ファイル不要）
- 日本語 UI。専門用語には初出時に短い説明（例：除雄＝自家受精を防ぐため、つぼみのうちにおしべを取り除くこと）
- Chromebook のマウス／タッチパッドとタッチの両方で操作できる。ボタンは大きめ
- 狭い画面（幅360px）でも崩れない

# データ
- 進み具合・種袋・畑の状態・ノートを localStorage に保存し、再読み込みしても続きから再開できる。「最初からやり直す」ボタンもつける
- ログインなし、名前などの個人情報は入力させない

# 技術の条件
- サーバーなしで動く静的な Web アプリ（GitHub Pages で公開できる）
- Gemini API などの外部 AI 呼び出しは入れない。API キーをコードに書かない
- 外部ライブラリは最小限（グラフも自前の SVG で可）
- 遺伝の計算（配偶子・受精・集計）は画面のコードと分けて1つのファイルにまとめる

# 今回の試作で確かめたいこと
- 除雄 → 筆で受粉 の操作が分かりやすく、楽しいか
- サヤを割る演出と、丸／しわ（黄／緑）の豆が見分けやすいか
- F1 の株のサヤから丸としわが混ざって出てくるか（豆の形＝子の遺伝子型）
- 除雄を忘れたとき、自家受精になったことが収穫時に分かるか
- 株を増やすと累計グラフが 0.75 に近づくか。?check の 10000 粒試算が期待値に収まるか
- 再読み込みしても続きから再開できるか
```

## 第2部：2回目以降に使う修正依頼の例

1. `?check を開いて表示された比率を見せてください。丸の割合が 0.74〜0.76、Lv4 が 9:3:3:1 から±1% に入っていなければ、遺伝の計算を直してください。`
