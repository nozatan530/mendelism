# 品種改良ゲーム（開発中・`npm run dev:game` で起動）

プレイヤーは新米の育種家。依頼の豆を作って納品し、畑を広げていく。本番ビルドには入らない（`VITE_GAME_MODE`）。Lv1〜4 のモードと保存データ（`mendel_garden_save_v2`）はそのまま残す。ゲームの保存は `mendel_breeder_v1`。

## ルール
- 最初の種は「純系 丸・緑」と「純系 しわ・黄」。何度でも使える
- 栽培は全株いっせいに進む。1回の収穫でシーズンが1つ進む。まけるのは育て始める前だけ
- 収穫豆は株ごとに分けて保管し、見た目と粒数だけを見せる。遺伝子型は見せない
- 納品すると、純系を求める依頼では、お客さんが1粒ずつ翌年まいて（30粒）違う豆が出ないか確かめる。答えの遺伝子型は明かさない
- 納品の失敗と期限切れで信用が1つ下がる（最初は3）。信用0で最初から
- 純系かどうかは、候補を1株ずつ自家受精させ、子がそろうかで確かめる（1株を交配と自家受精に分ける方式は採らない）

## 依頼
| # | 依頼 | 期限 | 達成後の畑 | 学ぶこと |
|---|---|---|---|---|
| 1 | 丸・黄を10粒 | 2回 | 6区画 | 交配と顕性 |
| 2 | しわ・緑の純系を5粒 | 2回 | 12区画 | 分離。潜性の見た目なら確かめなくてよい |
| 3 | 丸・黄の純系を10粒 | 3回 | 12区画 | 見た目と遺伝子型の違い |
