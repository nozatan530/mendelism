# メンデルの畑（mendel-garden）

## ひとことで
エンドウを「まいて・育てて・受粉させて・サヤを割って数える」作業を追体験しながら、分離の法則から検定交雑・独立の法則まで、自分のペースで解き明かしていく遺伝シミュレーター。

## 利用者と場面
- 高校生（生物基礎〜生物）が自宅で自主学習として使う。中学で3:1を習った人の復習にも使える
- Chromebook で1人1台。ログインなし
- 学びたいところまで進めればよい（レベル制。途中でやめても続きから再開できる）

## 学びの目的
- 遺伝の法則を「紙の上の記号」ではなく、栽培・交配・収穫・数える作業の結果として理解する
- 使い終わったとき、次のことを自分の言葉で説明できる
  - F1 がすべて丸になる理由（優性／劣性）
  - F1 の自家受精で丸：しわ ≒ 3：1 になる理由（分離の法則）。数が少ないとずれ、増やすと近づくこと
  - 見た目が丸の豆が AA か Aa かを、しわ（aa）との交配で見分ける方法（検定交雑）
  - 2つの形質（形・子葉の色）が 9：3：3：1 になる理由（独立の法則）

## 体験の流れ（利用者目線）
1. **畑に種をまく**：丸（AA）としわ（aa）の純系の豆を選んでまく → 発芽・成長・開花を早送りで見る
2. **受粉させる**：そのままだと自家受精。交配したい株は、つぼみのうちに**おしべを取り除き（除雄）**、別の株の花粉を**筆でつける**。除雄を忘れると自家受精してしまう
3. **収穫してサヤを割る**：サヤを1つずつタップして開け、中の豆の丸／しわを数える（豆の形は「中の子の遺伝子型」で決まる）
4. **謎解きノートに答える**：「なぜ F1 は全部丸？」などの問いに、仮説を選び・記録する → 次の栽培で確かめる
5. **F1 を自家受精させる**：F2 の豆を収穫。株数・サヤ数を増やすほど、累計の比が 3：1 に近づくグラフを見る（メンデルの実測 5474：1850 と比べる）
6. **レベルアップ**：検定交雑（正体不明の丸い豆を見抜く）→ 独立の法則（形＋子葉の色、9：3：3：1）へ進む
7. いつでも中断・再開。ノートのページが埋まっていく

### レベル構成
| Lv | テーマ | 主なミッション |
|---|---|---|
| 1 | 優性 | 丸×しわ を交配し、F1 が全部丸になるのを確かめる |
| 2 | 分離の法則 | F1 を自家受精し、F2 を数えて 3：1 を見つける |
| 3 | 検定交雑 | 「丸い豆 3 粒、どれが AA でどれが Aa？」しわと交配して見抜く |
| 4 | 独立の法則 | 丸・黄（AABB）× しわ・緑（aabb）→ F1 → F2 で 9：3：3：1 |

## 遺伝のモデル（指示書でそのまま数式・規則として渡す）
- 形：A（丸）が a（しわ）に対して優性。子葉の色：B（黄）が b（緑）に対して優性
- 配偶子：各遺伝子座から 1 つずつ、確率 1/2 でランダムに選ぶ。A と B は独立（連鎖なし）
- 受精：花粉（父）と胚珠（母）の配偶子を 1 つずつ合わせる。胚珠 1 つにつき 1 回、独立に乱数
- **豆の形・子葉の色は、その豆の中の胚（子）の遺伝子型で決まる**。母株の遺伝子型ではない。だから F1 株に実ったサヤの中に丸としわが混ざる
- 除雄していない花は必ず自家受精（他の株の花粉をつけても無効）
- 1 株あたりのサヤ数・1 サヤあたりの豆の数は少しばらつかせる（例：サヤ 4〜8、豆 4〜8）
- 確認用：F2 を 1 万粒シミュレートすると 丸：しわ ≒ 0.75：0.25、2 形質で 9：3：3：1 にそれぞれ ±1% 程度で収まること

## 画面一覧
- **タイトル／レベル選択**：進み具合、ノートの埋まり具合
- **畑**：区画に種をまく、成長の早送り、株をタップして状態を見る
- **花のアップ**：除雄（おしべをつまむ）、筆で花粉をとってつける
- **収穫台**：サヤを割って豆を見る・自動で数える
- **集計**：今回の数・累計の比のグラフ、メンデルの実測値との比較
- **謎解きノート**：問い・自分の仮説・確かめた結果（答え合わせと解説）
- **種袋（インベントリ）**：収穫した豆を世代・親の情報つきで保管し、次にまく豆を選ぶ（遺伝子型は検定交雑で見抜くまで「？」）

## データと公開範囲
- 保存：進み具合・種袋・ノートを端末のブラウザ（localStorage）に保存。サーバー保存なし
- ログインなし、個人情報なし（名前も入力させない）
- 一般公開してよい

## 試作で確かめたいこと（AI Studio Build で見たい点）
- 除雄 → 筆で受粉 の操作が、Chromebook のマウス／タッチパッドでわかりやすく、楽しいか
- サヤを割る手ざわり（アニメーション）と、豆の丸／しわが見分けやすい絵になっているか
- F1 の株のサヤから丸としわが混ざって出てくる（豆の形＝子の遺伝子型）が正しく動くか
- 株数を増やしたときに累計グラフが 3：1 に近づいていくか（確認用の 1 万粒試算も）
- 除雄を忘れたとき、自家受精になったことがあとで分かる仕掛けになっているか
- 再読み込みしても続きから再開できるか

## やらないこと
- 連鎖・組換え、不完全優性、伴性遺伝など Lv4 より先の内容（将来の拡張候補）
- クラスでの集計・対戦（Firebase なし）
- 実時間での栽培（成長はすべて早送り）
- 生徒の名前・成績の記録

## 反映した教訓
- シミュレーションは規則を数式・定数のまま指示書に書く → 「遺伝のモデル」節を設けた（coaster-mission）
- 表示だけでなく整合を数値で確かめる → 1 万粒の試算で比を確認する項目を入れた（coaster-mission）
- 取り込み後は「1人で使う」通しテストをする → 自宅で1人で進める前提なので、ヒントなしで Lv1→Lv2 を通せるかを確かめる（coaster-mission）
- 仕様を1枚にまとめてから頼む → レベル構成と遺伝モデルを先に固定した（lemonade-game-v2）
